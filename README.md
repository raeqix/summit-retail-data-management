
# Summit Retail | Data Management & Quality Audit

## Project Overview
This project demonstrates the process of transforming a messy retail customer and order dataset into a structured, standardized, and auditable Microsoft Excel workbook.

The objective was to improve data accuracy, identify duplicate records, standardize inconsistent information, and implement validation rules to reduce future data entry errors.

## Tools & Technologies
- Microsoft Excel
- Excel Tables
- Data Validation
- COUNTIF / COUNTIFS
- COUNTA
- SUMIF
- XLOOKUP
- Conditional Formatting
- Data Cleaning & Standardization

## Key Responsibilities
- Cleaned and organized customer and order records.
- Standardized customer names, phone numbers, city names, and order dates.
- Identified duplicate customer IDs and exact duplicate records.
- Implemented dropdown validation for order statuses.
- Applied data quality checks to identify incomplete records.
- Created an automated audit summary using Excel formulas.
- Organized the dataset chronologically by order date.

## Workbook Structure

**Raw Data**
Original dataset preserved for reference and comparison.

**Cleaned Data**
Standardized customer and order information with duplicate detection and data quality checks.

**Data Validation**
Validation rules and supporting quality control processes.

**Audit Summary**
Overview of record counts, duplicates, revenue, and records requiring manual review.
